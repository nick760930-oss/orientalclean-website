# 設計研究與轉化原則

本文件記錄三版概念在動工前的研究方向，以及如何把研究結果轉成東方繩洗自己的設計語言。研究對象只取其「做法」，不取其外觀。

## 一、研究對象與觀察

| 類型 | 參考 | 觀察到的做法 | 可轉化的原則 |
|---|---|---|---|
| 建築事務所 | Herzog & de Meuron（complete works 索引）、OMA、SANAA | 作品以編號、年份、類型、地點組成可檢索的索引；首頁常常只有清單或一張圖 | 案例是資料，不是圖卡。每個案例要有可比較的欄位與編號 |
| 建築攝影／出版 | 建築專書、作品集型網站 | 大圖、精準圖說、頁面節奏由照片控制，文字極少但每一句都指向照片內容 | 圖說寫「誰、在哪、做什麼」，不寫形容詞 |
| 工程顧問 | Arup Insights | 長篇文章以問題切入，由專業人員署名，文章與服務、專案互相連結 | 工程筆記要有審閱人、更新日期，並回連服務與案例 |
| 精品材料／家具 | Vitra、USM、石材與磁磚品牌 | 以材質、尺寸、表面處理為導覽；樣品冊式的排版 | 用「材質」當作入口：玻璃、磁磚、石材、金屬、接縫 |
| 汽車與精密設備 | Porsche 技術規格頁、Leica | 規格表、剖面、儀表；互動用來說明機構，而不是裝飾 | 設備與接近方式用規格與限制說明，互動要解釋工法 |
| 精品品牌 | Hermès、Aesop | 文字節制，句子短，不做形容詞堆疊；品牌色大面積而一致 | 品牌青藍用成「面」，不用成漸層或光暈 |
| 互動網站 | Awwwards 類型作品 | 好的作品把特效綁在一個核心隱喻上，只用一次、用到底 | 每一版只保留一個核心互動，其餘保持安靜 |

## 二、文字使用方式的觀察

1. 國際建築與工程網站的首頁標題多半是事實陳述（做什麼、在哪裡），很少用口號。
2. 案例標題以「案場名稱＋工項」為主，形容詞放在後面甚至不用。
3. 英文在這些網站中是導覽、分類與編號；主要資訊用使用者的語言。
4. 可信度來自可以被核對的資訊：日期、地點、範圍、限制條件、資料來源。

## 三、東方繩洗的設計原則

1. **先寫事實，再做視覺。** 每一個畫面都要回答：這是什麼問題、什麼材質、用什麼方式接近、留下什麼紀錄。
2. **品牌青藍是主角。** 以 Logo 實際色 `#74C7D6` 為核心，`#00B5D2` 為 Logo 青色底版；文字用深海青確保可讀。不使用紫藍漸層、霓虹與發光球。
3. **Logo 放在正確的底色上。** 使用 Repository 內正式檔案（裁切留白，不重畫），放在官方青色底或白底上，大小節制。
4. **繩索是唯一的形。** 繩索來自 Logo「繩」字下方的編織紋與實際作業。三版分別以線（A）、裁切（B）、時間（C）表現，不另加無意義幾何。
5. **案例是核心內容。** 三版的案例瀏覽方式完全不同：索引表（A）、印樣與圖版（B）、場景膠卷（C）。
6. **沒有資料就寫「待補資料」。** 不補數字、不補證照、不補客戶名稱。
7. **特效有降級。** 每一個動畫都有 Reduced Motion、低效能裝置與圖片缺失的處理。主要文字永遠在 HTML。

## 四、三版方向摘要

| | A 立面索引 | B 現場紀錄 | C 垂降 |
|---|---|---|---|
| 核心隱喻 | 工程圖與材料樣本冊 | 建築出版物與現場攝影 | 一次由屋頂到地面的作業時間 |
| 資訊架構起點 | 現場問題 → 材質 → 工法 | 案例 → 工法 → 筆記 | 作業順序與接近方式 |
| 首頁 | 無照片，可操作的立面判讀圖 | 封面照片、目錄、圖版 | 可刮除水膜的現場畫面與場景序列 |
| 案例瀏覽 | 可篩選的索引表 | 印樣（Contact sheet）與放大鏡 | 橫向拖曳的場景膠卷 |
| 字體 | 無襯線粗黑＋等寬編碼 | 明體標題＋黑體圖說 | 黑體＋儀表數字 |
| 動態 | 繩索物理 | 遮罩展開、裁切、Match Cut | 捲動控制時間、WebGL 水膜 |
