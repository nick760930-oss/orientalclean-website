`.vercelignore`。正式站的頁面、圖片、`robots.txt`、`sitemap.xml` 與 SEO 修正都沒有被修改。

## 共通內容（三版相同）

- 6 項服務頁、8 個案例頁、10 篇工程筆記、公司、聯絡，每版 30 頁。
- 公司資料、電話、Email、LINE、地址、營業時間與 12 個服務縣市，全部取自 `main` 分支現有資料。
- 案例只使用正式站已公開的案場與照片；沒有資料的欄位一律標示「待補資料」。
- 正式站上寫到的證照、零工安紀錄、評價數量與參考價格，都列為「待公司確認」，沒有在新版內容中直接宣稱。
- IRATA：只寫「公司資料提及雙繩作業參考 IRATA 規範」，不寫成認證。
- 沒有任何一版使用貨車照片、AI 生成照片或假的施工前後對照。
- 詢價入口：勾選問題、建築類型、地區與樓層，頁面即時組成一段訊息，可以一鍵複製並開啟 LINE
  （預先帶入訊息）、以 Email 寄出，或直接撥打電話。不會自動送出或儲存任何資料。

## A｜立面索引　FACADE INDEX（品牌系統型）

**設計說明**
以工程圖與材料樣本冊為藍本的品牌系統。首頁不用照片，只用 Logo 青藍色面、深海青文字與一張可操作的示意立面：
把雙繩拖到玻璃、磁磚、石材、金屬、塗裝或接縫上，判讀卡會即時說明常見問題、判斷方式與對應工法。
資訊架構從「現場問題」開始，再連到材質、工法與服務。案例以可篩選的索引表呈現；照片只在進入案例頁後才出現，
由一片青藍色面收起帶出。

**互動方式**
- 立面判讀：拖曳、點選、鍵盤方向鍵或材質按鈕移動繩索；工作繩與確保繩以 Verlet 物理擺動
- 問題索引：10 個現場問題可展開，連到服務與工程筆記
- 案例索引表：依工項與接近方式篩選，整列可點；手機改為堆疊資料卡
- 服務頁與文章頁：固定段落導覽與閱讀進度
- 案例頁：青藍色面收起帶出第一張照片、Before／After 滑桿

**品牌色**：`#74C7D6`（Logo 實際色，主色面）、`#00B5D2`（Logo 青色底版，繩索與作用中狀態）、`#0E3A43` 深海青文字、`#EAF6F8` 冰藍、白。

**案例瀏覽**：索引表（編號、案場、地區、建築類型、工項、材質、接近方式、期間、照片數）→ 案例頁左側固定 17 欄案件資料表，右側照片序列。

**知識文章入口**：主選單「現場問題」→ 問題索引＋依分類排列的工程筆記；首頁有「從現場問題開始」與「工程筆記」兩區。

**效能降級**
- 首頁首屏只有 SVG 與文字，沒有照片；標題字型依實際用字子集化，約 90 KB
- Reduced Motion 與低效能裝置（Save-Data、記憶體 ≤ 2 GB、核心數 ≤ 2）：繩索改為靜態直線，不做進場垂降
- 繩索靜止後停止運算；只在立面進入畫面時啟動
- 圖片載入失敗時顯示提示

**已知問題**
- 立面圖是示意，不是特定建築（圖上已標示）
- 觸控裝置上垂直拖曳會捲動頁面；移動繩索請點選或水平拖曳，也可用材質按鈕
- 工程紀錄表是欄位範例，不是實際案場資料（表上已標示）

## B｜現場紀錄　FIELD RECORD（攝影編輯型）

**設計說明**
以建築出版物為藍本，案例優先於服務。首頁像一期刊物：封面照片從一條繩索寬的縫隙展開成全幅，接著是目錄、
一個案例特寫、六張工法圖版與一篇工程筆記，最後以「版權頁」呈現公司資料與委託方式。標題用明體，圖說用黑體；
品牌青藍只出現在標記線、標籤與版權頁色帶。案例以印樣（Contact sheet）瀏覽，點選任一格即可在放大鏡中
左右翻看所有案場照片；從目錄進入案例時，縮圖以 Match Cut 接到案例封面。

**互動方式**
- 封面：縫隙展開、捲動時收緊裁切
- 照片遮罩展開（只作用在照片，文字不做淡入）
- 跨頁 View Transitions：目錄與印樣縮圖接到案例封面（Chrome 126+、Safari 18.2+；其他瀏覽器直接換頁）
- 目錄對話框（全站導覽）
- 印樣放大鏡：鍵盤左右鍵、滑動、上一張／下一張，跨案場連續翻看
- 印樣每列可橫向捲動；工項篩選；Before／After 滑桿

**品牌色**：Logo 官方青色版本置於紙白 `#F7F9F9`；`#74C7D6` 標記線、圖版標籤與版權頁色帶；文字 `#10262B`。

**案例瀏覽**：印樣（每個案場一列、每張照片一格）＋放大鏡 → 案例頁：全幅封面、案件資料欄、圖序、施工前後、下一個案例。

**知識文章入口**：主選單「筆記」→ 首篇大標題＋清單；首頁「工程筆記」專欄；文章頁側欄段落導覽、相關服務與相關案例縮圖。

**效能降級**
- 明體標題字型依實際用字子集化，約 270 KB（Google Fonts 分片約 1.6 MB）
- Reduced Motion：封面直接全幅、不做遮罩展開、關閉 View Transitions
- 低效能裝置：不做遮罩展開與捲動裁切
- 首屏照片優先載入，其餘延遲載入；每張照片都有寬高比與主色底，避免版面跳動
- 瀏覽器不支援 `<dialog>` 時，目錄按鈕改回首頁

**已知問題**
- 現有照片幾乎都是施工中；施工前與完工同角度照片待補，Before／After 左側顯示待補
- 大江購物中心矽利康、聯聚東方、高雄流行音樂中心的原檔解析度低，以接近原始尺寸顯示並標註
- 明體字型是子集，新增標題文字後需要重新建置（建置流程已自動處理）

## C｜垂降　DESCENT（空間／電影型）

**設計說明**
以一次作業的時間為結構：從玻璃外側開場，經屋頂固定點、立面判讀、清洗、修繕、防水，到地面與完工紀錄。
桌機上往下捲動會讓場景橫向前進，右側高度計由屋頂降到地面，捲動控制的是時間；手機上同一組場景改為原生左右滑動。
開場是一張現場照片上的 WebGL 水膜：在照片上拖曳，就像刮刀刮過玻璃，露出清楚的現場照片。深海青與霧黑為底，
品牌青藍作為儀表與光線。案例以可拖曳的橫向膠卷瀏覽；接近方式頁用示意立面比較六種接近方式。

**互動方式**
- 捲動控制橫向場景與高度計；滑鼠橫向拖曳、鍵盤左右鍵、場景按鈕、高度計跳轉
- WebGL 水膜：折射、流動水痕、水珠、刮刀遮罩、「重新噴水」
- 案例膠卷：拖曳、按鈕、鍵盤；照片序列同樣可橫向瀏覽
- 接近方式：分頁＋示意立面同步標示（繩索、吊籠、高空車、吊車、施工架、地面）
- 文章閱讀進度、Before／After 滑桿

**品牌色**：`#74C7D6` 儀表、按鈕與作用中狀態；`#00B5D2` 輔助；背景 `#071B20` 深海青、`#0C262C`；文字 `#E8F1F3`；Logo 使用官方白色版本。

**案例瀏覽**：橫向膠卷（每格一個案場）＋清單表 → 案例頁：全幅標題照片、橫向照片序列、案件資料面板、施工前後、下一個案例。

**知識文章入口**：主選單「工法手冊」→ 依作業順序分章（勘查與判斷、清洗、修繕、防水、接近方式與發包）。

**效能降級**
- 手機與觸控裝置：不綁定捲動，改原生橫向滑動（scroll-snap）
- Reduced Motion：同上，水膜不流動、不做示範刮除
- 低效能裝置：水膜改用 Canvas 2D 霧面、關閉視差
- WebGL 或照片載入失敗：保留原始照片並顯示提示；載入時顯示百分比進度
- 水膜只在可見時繪製，上限 30fps，解析度上限 1.5 倍；下一個場景的照片提前載入
- 首屏照片 preload；水膜在首屏照片顯示後才載入，不影響 LCP；CJK 網頁字型不載入（約 33 KB 字型）

**已知問題**
- 桌機捲動帶動橫向移動，對部分使用者不直覺；已提供按鈕、高度計與鍵盤操作，停下時會對齊最近場景
- 開場水膜是效果，不是施工前後對照（畫面上已標示）
- WebGL 在 iPhone Safari 的效能需要實機驗收（本環境只能以軟體 WebGL 測試）
- 「屋頂」場景照片（聯聚東方）解析度低

## 三版差異

| | A 立面索引 | B 現場紀錄 | C 垂降 |
|---|---|---|---|
| 資訊架構起點 | 現場問題 → 材質 → 工法 → 服務 | 案例 → 工法 → 筆記 | 作業順序與接近方式 |
| 首頁表現 | 無照片，可操作的示意立面與判讀卡 | 刊物封面、目錄、特寫、圖版、專欄 | 水膜開場＋七個橫向場景 |
| 導覽方式 | 固定選單＋索引 | 目錄對話框（全站） | 高度計＋場景按鈕＋選單 |
| 互動方式 | 繩索物理、拖曳判讀、展開、篩選 | 遮罩展開、Match Cut、放大鏡 | 捲動控制時間、WebGL 水膜、拖曳膠卷 |
| 攝影使用 | 只在案例頁出現 | 全站主角，大圖與圖說 | 場景畫面與全幅標題照片 |
| Typography | 無襯線粗黑＋等寬編碼 | 明體標題＋黑體圖說 | 黑體＋窄體儀表數字 |
| 動態語言 | 物理、低調 | 裁切與轉場，只作用在照片 | 時間軸與空間移動 |
| 案例瀏覽 | 可篩選索引表 | 印樣＋放大鏡 | 橫向膠卷＋清單 |
| 品牌氣質 | 精準、系統、工程圖 | 安靜、出版、紀錄 | 電影感、儀表、現場 |
| 背景 | 白與 Logo 青藍色面 | 紙白 | 深海青 |
