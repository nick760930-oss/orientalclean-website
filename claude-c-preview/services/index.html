工程服務

外牆清洗、修繕、防水、檢查與高空作業

依建築條件、外牆材質與現場問題決定施工方式。每一項服務都寫明判斷方式、工法、限制與交付紀錄。

Facade cleaning

外牆清洗

先確認材質與髒污類型，再決定用水、藥劑與接近方式。

同一棟建築，玻璃、磁磚、石材與金屬板需要不同的清洗方式。東方繩洗在報價前確認清洗部位、外牆材質、髒污類型與現場條件，在不顯眼處試洗後，再安排繩索、吊籠或地面作業。

工法：外牆清洗分級、純水清洗、逆滲透純水系統、高壓清洗、藥劑清洗

Facade repair

外牆修繕

先確認範圍，再評估灌注、局部修補或打除重做。

磁磚空鼓、剝落與裂縫，處理方式取決於範圍與基層狀況。只憑一張缺角照片無法決定工法。東方繩洗先以敲擊與目視確認範圍、標在立面圖或照片上，再說明各工法的適用條件、限制與費用差異。

工法：外牆檢測、空鼓灌注、局部修補、磁磚打除、基面整理、水泥打底、磁磚鋪貼與填縫、裂縫修補

Waterproofing & sealant

外牆防水

先找水從哪裡進來，再決定用什麼材料。

室內出水的位置，不一定就是外牆進水的位置。水可能從窗框接縫、磁磚縫、裂縫或女兒牆進入，在牆體內移動後才出現。東方繩洗先整理發生時間與降雨關係，找出可能水路，再決定處理部位與材料系統。

工法：矽利康更新、外牆防水、裂縫修補

Facade inspection

外牆安全檢查

把看不到的問題，標在看得到的位置上。

外牆檢查的目的，是讓管委會與業主知道哪裡有問題、範圍多大、先處理哪裡。東方繩洗以繩索接近立面，目視與敲擊檢查，把異常位置標在立面圖或照片上。無法接近的位置也會註明。

工法：外牆檢測、完工紀錄

Access methods

高空作業與接近方式

接近方式是手段。依工項與現場條件選擇。

樓層高低不能單獨決定接近方式。屋頂能否進出、固定點在哪裡、立面有多少外凸物、地面有沒有停放空間，以及要帶多少材料上去，都會影響選擇。東方繩洗把接近方式與工項一起評估。

工法：雙繩高空作業、吊籠、高空車、吊車、施工架、地面作業

Special access work

特殊高空作業

從施工位置，確認可行的維護安排。

商場挑空的燈箱、屋頂造型構件、高處燈具，常常沒有固定的維護通道。東方繩洗先確認設備型號、尺寸、固定方式與可施工時段，再決定接近方式與備料。

工法：雙繩高空作業、高空車、完工紀錄
