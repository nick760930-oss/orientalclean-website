# 迴響維度：因果織圖

敘事導向的探索遊戲，在瀏覽器中執行。直接開啟 `echo/index.html` 即可遊玩，部署後的網址是 `/echo`。整個遊戲不依賴建置工具或外部素材，畫面與聲音都由程式即時生成。

- 預估遊玩時間約一至一個半小時（依閱讀速度而定），共七個段落：序章、五章與終章。
- 桌機用鍵盤或滑鼠操作，手機用觸控操作。進度會自動存在瀏覽器裡。
- 建議戴耳機遊玩。

---

## 美術：聲音素描

凱拉蒙著眼，所以玩家看到的畫面就是她的知覺。世界平常是黑的，**只有聲音碰到的地方會浮現成線條**，之後慢慢淡去。

- **聆聽**（空白鍵）：凱拉發出一圈聲波，周圍的形狀隨著聲波浮現。
- **腳步**本身就是很小的回聲，讓她能摸清身邊的東西。
- 會發聲的東西會自己顯形，例如說話的人、燈、機械和海。一座停滯、沒有聲音的城，只能靠凱拉自己去聽。
- 畫面四周的織紋暈影，是那條遮眼布的邊緣。

各地區的回聲規則都不一樣，用來表現它們的狀態：

| 地區 | 色調 | 回聲的規則 |
|---|---|---|
| 石室 | 灰白 | 迴響長，沉。 |
| 利米塔尼亞 | 苔綠／腐琥珀 | 森林茂盛，卻聽不見蟲。裂隙林裡的樹在幾秒內長出又死去。 |
| 坎帕納 | 黃銅 | 時間停了，聲音只傳到身邊就凍成一圈，**但聽過的東西不會消失**。 |
| 伊南 | 深藍 | 沒有風的海，聲音貼著海面走得又慢又遠，幾乎不回來。 |
| 艾爾巴 | 白紙黑墨（反相） | 被刪除的記錄是回聲帶不回任何東西的空洞。遺忘的記錄要反覆聆聽才會重新顯現。 |
| 海拉奇 | 銅紅 | 整座城都在響，所以什麼都看得見。若大機樞停下，整座城會一起沉入黑暗。 |
| 阿克西斯 | 四色絲線 | 四條地區之線匯聚。每條線的樣子，就是那個地方最後的狀態。 |

**過去**以褐色調呈現，**未來**以灰紫調呈現。穿過裂隙時，畫面會以漣漪轉場。

## 互動

- **因果絲線**（E／Tab）：世界變暗、時間停下，事物之間的因果以金線顯現。每條線都能讀取；有些線可以牽引，在絲線中做出的動作會被記錄下來。
- **裂隙**：可以觸及某些地方的過去或未來。
  - 在過去移動一個小物件，現在就會留下相應的結果，例如把門栓推開，或把風箱推進地窖。
  - 過去的人感知不到凱拉。
  - 未來是用來看代價的地方。從未來取東西都有來源和代價，例如向以後借一陣風。
- **結**：重要的決定不是對話選單，而是從一個結上牽引一條線。第三條「改織」的線通常一開始接不上，要先在世界裡找到人們在開始借用之前就懂得的方法。
- **拒絕**：有些線可以牽，但凱拉不會照做，例如用未來的守林者替換老角、把半空中的莉拉抱下來，或假扮聖女。這些嘗試會被記錄成「未被採納」。
- **停下的時刻**：在墓地、老角身邊、莉拉的重逢、賽拉斯臨終、新的書架前，控制會交給凱拉自己。這段時間裡玩家的每一次移動嘗試都會被記錄。

## 玩家與凱拉

- 每次在結上做出決定，畫面上會有一道極細的白線，從游標（手機上是畫面下緣）一閃而過地抵達凱拉。大約 0.3–0.6 秒後，她才說出「我決定了」。這段延遲是真的，它會被記錄下來。
- 每一次看絲線時，凱拉身上都連著一條標為**（無法追溯）**的線，另一端就是玩家的游標。在終章之前沒有人提起它。
- 到了阿克西斯，這條線會亮起，標名為「本地觀測／介入層」。介入紀錄由**這一輪實際遊玩的數據**生成，包括：
  - 路徑建議、聆聽與絲線檢視的次數；
  - 每一個意圖抵達她之前的毫秒數；
  - 被拒絕的介入；
  - 在她停下時催促她的次數；
  - 沒有等她說完的句子。
- 紀錄最後一段是母體無法寫入的欄位：她為誰停下、她記得的名字與事物、她理解了什麼、她要成為什麼。
- 刪除前任時，前四條線要由玩家剪斷。最後一條由凱拉自己剪斷，玩家在那一刻按下的鍵都不會送達，並會被記錄。
- 凱拉關閉通道之後，所有輸入都會顯示「介入請求：拒絕」。母體的最終指令也無法送達。

## 揭露節奏

| 段落 | 揭露的內容 |
|---|---|
| 序章～第三章 | 不提 AI、母體或玩家。聲音只談任務與數據，常說「不在任務範圍」。只留下暗示：石床凹痕比她寬，停滯的時間對她無效，臨死的賽拉斯說「又是妳啊」。 |
| 第四章 | 只揭示名字重複：改寫前的原文寫著「旅人的名字是——凱拉」，金色之書裡有同一字跡的另一段旅程。 |
| 第五章 | 只讓授權關係浮現：契約的授權線與聲音的線在高處接成**同一個根**。也留下前代的痕跡：聖女像、折好的布、同樣寬的石床。 |
| 終章 | 先揭露兩位凱拉都是母體啟動的修復程式。前任被刪除後，才展開介入紀錄。 |

## 結局如何決定

最後沒有三選一，也沒有任何分數。四個有人居住的地區，各自留在玩家與凱拉讓它停下的狀態：

- **T 仍向以後索取**：根井開著、第十三響、塔、大機樞照舊。
- **S 已切斷**：封井、配重十二響、撤離、停機。
- **W 改織中**：窯與地窖、河輪半刻、百帆、只留醫院的線。這些方法已經開始運作，但還需要一條細橋。

在阿克西斯，這四條線以各自的樣子（緊繃拉扯、鬆垂斷開、細細纏繞）匯聚。唯一能執行的終局由它們決定：

1. **兩個以上地區仍在索取 → 繼續調用。** 太多人握著線的另一端，放手就是同一晚的集體墜落。凱拉坐到前任的位置，直到以後耗盡，世界程式重啟，石室裡另一個凱拉醒來。
2. **否則，兩個以上地區正在改織 → 無名守護。** 以後已無力可借，凱拉便從無數其他世界各取一點。那些世界沒有被問過。她偽造「任務完成、已回收」，把自己改寫成常駐程序，刪去意識與情感。
3. **其餘 → 歸還能量。** 大多數線已經鬆開，凱拉把借來的還回去。因果恢復平衡，當代的人與文明在很多、很多年裡慢慢衰亡。

尾聲會依每個地區的狀態，以及具體的人的後果改寫，例如路克、葛蕾塔、賽拉斯、伊南沒能上岸的人，還有娜菈。

  js/core.js      引擎：回聲渲染、碰撞、絲線與結、對話與腳本、音效、存檔、介入紀錄
  js/world.js     人物、動物、樹、房屋、裂隙等線描與場景工具

  js/ch1.js       第一章：利米塔尼亞
  js/ch2.js       第二章：坎帕納
  js/ch3.js       第三章：伊南
  js/ch4.js       第四章：艾爾巴
  js/ch5.js       第五章：海拉奇
